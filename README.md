# Minimalistisches E-Rechnungs-Tool (XRechnung 3.0 / UBL)

Ein rein browserbasiertes, datenschutzfreundliches Tool zum Erstellen von E-Rechnungen (XRechnung 3.0 Standard) und optionalen PDF-Rechnungen. Speziell optimiert für Kleinunternehmer (§ 19 UStG) und den schnellen, unkomplizierten Einsatz ohne Cloud-Zwang.

## 🚀 Features
* **100% Client-side:** Alle Daten bleiben lokal in deinem Browser (keine Server-Speicherung, voller Datenschutz).
* **XRechnung 3.0 Konform:** Generiert valide UBL-XML-Dateien nach EU-Standard (EN 16931).
* **Kleinunternehmer-Modus:** Berücksichtigt automatisch § 19 UStG (kein MwSt.-Ausweis, korrekte Befreiungstexte).
* **Zwei-in-Eins:** Erzeugt auf Wunsch parallel eine saubere PDF-Rechnung direkt im Browser (via jsPDF).
* **Keine Installation:** Einfach die HTML-Datei herunterladen und per Doppelklick im Browser öffnen.

## 🛠️ Nutzung
1. Lade die `index.html` herunter.
2. Öffne sie in einem beliebigen modernen Browser (Chrome, Firefox, Safari, Edge).
3. Füge deine Unternehmens- und Kundendaten ein (werden auf Wunsch im Browser-LocalStorage gespeichert).
4. Klicke auf **"E-Rechnung erzeugen & herunterladen"**.
